# 🎥 Face Detection System

## Overview
Welcome to the **Face Detection System** project! This is a powerful solution to detect faces in images using machine learning techniques. It provides an intuitive interface for users to upload images and get real-time face detection results.

This project uses pre-trained models like **Haar Cascade** and can be easily extended to include other face detection models such as **YOLOv8** or **OpenCV DNN**.

---

## ⚡ Key Features
- **Real-Time Face Detection**: Detect faces from uploaded images.
- **Model Flexibility**: Built with easy integration for other models (e.g., YOLO).
- **Interactive Interface**: Upload images via a user-friendly web interface.
- **Confusion Matrix**: Evaluate performance with accuracy and confusion matrix metrics.
